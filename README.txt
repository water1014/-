鞠式养成工作台 · 使用说明
============================

文件清单（都在本文件夹）：
1. index.html   —— 主程序（完整功能版）
2. manifest.json —— PWA 清单（用于装桌面 App）
3. sw.js        —— 离线缓存（PWA 用）

怎么用：
· 电脑：双击 index.html 用浏览器打开即可。
· 手机：把 index.html 保存到手机，用浏览器打开即可。
· 想装成 App：把三个文件传到 GitHub Pages 后，手机浏览器打开网址
  → 点「添加到主屏幕」，桌面就有图标，全屏+离线可用。

本版新增功能：
· 🔤 全局字体控制（装修工坊：中英文字体 + 字号滑块）
· 💾 数据备份导出/导入（装修工坊）
· 🎬 每个栏目的 B站视频学习区（粘贴BV号/链接直接播放）
· 🎬 视频专栏（汇总所有栏目的视频，菜单里）
· 🎬 视频区开关（装修工坊里按栏目开关）
· 📕 小红书收藏专栏（存链接+分类+要点，免费）

数据存在浏览器 localStorage，删除浏览器数据会清空，记得定期导出备份。
