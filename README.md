# 🌸 鞠式养成工作台

像小鞠一样闪闪发光的工作台。单文件、纯前端、数据存本地。

## 文件清单
| 文件 | 说明 |
|---|---|
| `index.html` | 主程序（完整功能版，浏览器打开即用） |
| `manifest.json` | PWA 清单（用于装桌面 App） |
| `sw.js` | 离线缓存（PWA 用） |

## 使用方式
- **电脑**：双击 `index.html`，浏览器打开即可
- **手机**：浏览器打开 `index.html` 即可
- **装成 App**：打开本页网址 → 浏览器菜单「添加到主屏幕」→ 桌面有图标，全屏 + 离线可用

## 功能一览
- 🌸 今日鞠式日程（四象限 + 打卡 + 复盘）
- ✨ 精致感修行 / 🧘 体态与气质 / 📚 学识进阶·六级 / ⚔️ 拾薪筑途·考公
- 💰 银两台账（收支 + 预算）
- 🎬 视频学习：每个栏目可加 B站视频 + 视频专栏汇总 + 按栏目开关
- 📕 小红书收藏专栏（存链接 + 分类 + 要点）
- 🔤 全局字体控制（中英文字体 + 字号）
- 💾 数据备份：导出 / 导入 JSON
- 🎨 装修工坊：主题色 / 毛玻璃 / 圆角 / 背景图

## 数据说明
数据保存在浏览器 localStorage。**删除浏览器数据会清空**，记得定期在「装修工坊 → 数据备份」里导出。
